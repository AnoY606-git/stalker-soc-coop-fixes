# garbage_soc_quests: the Garbage quests in the order of the original SoC (phase 2 of "the quests must match the original")

Request (maintainer FOSTER): "the quests themselves must be remade to match the original SoC". Phase 1 (`soc_task_texts`) changed the texts. This patch does the
Garbage part of phase 2 (who gives the task, which steps exist, in which order). It builds on `garbage_gray` (Seriy's fight), `garbage_duty` (checkpoint, gate, boar
verdict) and `campfires` (job logic); none of their behaviour is undone. Code-only, UNTESTED in the game (offline checks and a game test hook are below).

## What the original SoC does (Steam SoC 1.0006 `tasks_garbage.xml`, `info_l02garbage.xml`, `info_escape.xml`, `dialogs_garbage.xml`, `dialogs_escape.xml`, `gulag_garbage.ltx`; Russian text from the SoC add-on of the CoP port)
* `garbage_meet_stalker` ("Meet with Seriy"): ONE task with two objectives. Objective 0 is Fox's briefing (given by Fox's dialog on Cordon, `garbage_meetstalker_start`,
  Fox: "Seriy is sitting in the hangar"), objective 1 "Learn something of Strelok from Seriy" has Seriy's map spot. There is no "help Seriy fight off the bandits" objective:
  the bandits (`gar_seryi_bandits`) simply attack him when the player comes near, his dialog (`gar_seriy_start`) is closed until they are dead ("this ain't no time for talking").
  Seriy's talk (phrases 22, 221 / 222, 2211 / 2221, 2212 / 2222: with Fox's introduction or without) gives `garbage_meetstalker_done` and `agr_krot_band_start` (task `agr_meet_krot_band`) and pays 2500.
* `gar_car_graveyard_quest` ("Respond to the call for help") comes on the arrival (`gar_start_quest`), `gar_help_dymon` ("Repel the bandit raid") when the player says "OK, I'll help you" to Bes
  (`gar_hellcar_help`), the third objective is "Talk to Bes" (payment 2000 in the dialog).
* `gar_kill_boars` ("Help the Duty checkpoint"): objective 0 header (the Duty radio call), objective 1 "Kill the boars" (`gar_kill_boars_done`), objective 2 "Talk with the Duty commander"
  (`gar_dolg_blockpost`, done by `gar_kill_boars_request`: the commander's dialog 222 / 1231 or the "normal" verdict after the wave). SoC has no money for it; the reward is the passage.
* The radio lines `grey_grey_1` and `neutrals_commander_pda_1` that the level maker uses for the calls of Seriy and Bes are in the SoC archives but not in SoC's `script_sound.ltx`: SoC never plays them.

## Soft locks and co-op rules
* Every task above is handed to EVERY player by a server tick (1 s, `scripts\coop_scn_garbage_soc.script`, loaded by the Scene Director like the Agroprom one): once per player and Lua VM, while its stage is open; a stage closes with the same flags that complete the task, so nothing finished comes back after a reload; late joiners get the open stage only; dead players get theirs when alive. The stock `give_task` effects stay in the logic (harmless duplicates).
* Flags are shared story flags (saved, synced): the arrival flag, the dialog flags, `GAR_SOC_DUTY_REPORT_INFO`, `GAR_SOC_DUTY_PAID_<NAME>` (per player). The dialog actions run on the talking player's machine; the money is paid in the client context only.
* Seriy / Bes / the commander dead (their logic is `invulnerable`, but a kill by script or a mod is possible): the server gives the flags their dialogs would give (Seriy: the talk flag and so the Agroprom task; Bes: both flags; the commander: the report flag and `GAR_FREE_PASS`, so the gate opens).
* The Duty wave no longer depends on the host: a player staying near the zone starts it (the favor and the zone start it too).
* Rewards as in SoC (coordinator decision): Seriy 2500 and Bes 2000 are paid in the last phrase of their dialogs (`pay_seriy`, `pay_bes`: `dialogs.relocate_money_to_actor`, once per player name through the flag `GAR_SOC_PAID_<SERIY|BES>_<NAME>`) to the TALKING player, like the commander's 1500; the 5000 `reward_money` of `gar_start_talk_to_gray_quest_task` and `gar_start_talk_to_devil_1_quest_task` is removed. The dialog closes when its flag is set, so the first player who talks is the one paid (as in SoC).
* Not changed on purpose: the Yurik story (mod-only, tasks hidden), the Garbage meeting-place tasks, Gray's fight, the Duty gate and the boar verdict of `garbage_duty`.
* Voice: SoC has no recorded lines for the dialogs of Seriy, Bes, Fox or the commander (the Steam archives hold voice for the Barkeep, the trader, the scientists and the Osoznanie only); the Duty verdict lines are already in `garbage_duty` with `voice_lang()`. The only Seriy line that exists, `grey_grey_see_actor` (SoC plays it when he sees the player within 30 m), is not used here: it needs a client-side distance check of its own.

## Payments on every host type (v1.4.2)
Bug: the three payments (Seriy 2500, Bes 2000, commander 1500) were gated on `OnClient()`, which is false for the HOST player of a listen host, so the host was never paid
(and the paid flag was already set, so no second try). Now (`coop_scn_garbage_soc.script`, `talker()` + `pay_to_talker()`), the way `repeatable_quests` pays (`dialogs.relocate_money_to_actor`
called directly, it finds the player speaker itself and worked from both contexts in the fetch test), with no `OnClient()` gate:
* the TALKER is the player whose own actor (`getLocalActor()`) is one of the two speakers of the dialog action (the opening's rule); a machine whose local actor is not a speaker pays
  nothing (a listen host looking at a remote player's talk; a dedicated server has no local actor at all);
* the paid flag `GAR_SOC_PAID_<KIND>_<NAME>` / `GAR_SOC_DUTY_PAID_<NAME>` is given first, then the money: a listen host runs the action in its server and its client context, the second run
  finds the flag and pays nothing, so exactly one payment per player and reward on any host type;
* both speakers nil (the in-game test hook calls the helpers directly): the local player counts as the talker. The test hook no longer needs `GARSOC_FORCE_CLIENT`.
Offline: `tests\garbage_chain_mock_test.py` ALL PASS (63 checks, 7 new): host player on a listen host paid once from server + client contexts, a remote player's talk pays nothing on the host machine,
the remote player's own machine pays him once per reward whatever the speaker order, dedicated server pays nobody and sets no flag, the host is still paid afterwards, commander report on a listen host.
Not run in the game (offline task).
