# Radar, X-10, Pripyat, CNPP, Sarcophagus and Control Monolith: the quest chain of the original SoC (phase 2)

Request (maintainer FOSTER): "the quests themselves must be remade to match the original SoC". Phase 1 (texts) is `patches\soc_task_texts` (its section "Phase 2" listed the differences for these levels). Done before: Cordon (`cordon`), Garbage (`garbage_soc_quests`), Agroprom (`agroprom_soc`), Dark Valley / X-18 (`soc_dv_x18_quests`). This patch does the last chapters. The Barkeep's start of the Radar job is not touched (owned by the Bar and Army Warehouses patches; this patch starts at "X-10 entered").

## The original SoC chain (Steam SoC 1.0006: tasks_radar.xml, tasks_aes.xml, tasks_sarcofag.xml, tasks_deadcity.xml, info_l11pripyat.xml, info_l12u_sarcofag.xml, level.spawn of l11_pripyat / l12u_sarcofag)
1. `bar_radar_deactivate` objective 3 "Deactivate the Brain Scorcher" (inside X-10), then `rad_get_to_aes` "Reach the power plant": 0 the Barkeep's briefing, 1 "Meet the group of stalkers", 2 "Follow the group of stalkers", 3 "Find the path to the Chernobyl NPP", 4 "Find the entrance to the sarcophagus".
2. `cit_doctor_task` "Secret stash at Pripyat" (given by the Doctor in Dead City): 1 "Get to the hotel", 2 "Find the room with the secret stash", 3 "Look the secret stash over". The stash is in the Pripyat hotel (`pri_hotel_zone`, `pri_hiding_place_zone`, item `pri_decoder` at 99.65 / 4.9 / 123.0); taking the DECODER sets `pri_monolith_decoder_got`, which gives `sar_secret_lab`. The Preacher does not exist in SoC.
3. Sarcophagus: `sar_monolith` "Wish granter": 0 "Get to Monolith" (the call), 1 "Sneak in to the sarcophagus" (zone `sar_monolith_find`), 2 "Find the Wish Granter". `sar_secret_lab` "Secret lab" (needs the decoder): 0 "Enter the secret bunker", 1 "Find the hidden door" (zone `sar_secret_room`, a 59 m corridor), 2 "Open it using the decoder" (door `sar_door`, zone `sar_decoding_rest`), 3 "Find out what is behind the door" (`sar_enter_command_center`).
4. `sar_monolith_destroy` "The Monolith's secret": 0 "Infiltrate the secret lab" (+ the Doctor's briefing), 1 "Solve the Monolith's secret". Then `sar_warlab` "The Zone's secret": "Meet whoever is behind the Monolith" (the C-Consciousness only TALKS to you; no kill step).
5. `aes_military_task` "Operation Monolith" (the military assault on the power plant with the squads Sapsan, Korshun, ...).

## How it works
`coop_soc_aes.script` (loaded by `coop_scn_soc_aes.script`, like every `coop_scn_*`): a server tick (1 s), same pattern as `coop_soc_dv.script` and `coop_scn_garbage_soc.script`.
1. `progress()` derives the SoC infos from the world and makes the chain monotonic (a later flag also sets every earlier one): arrival on a level (`PRI_START_GO_TO_CNPP_QUEST_TASK_INFO`, `AES_1_START_GO_TO_SARCOFAG_QUEST_TASK_INFO`, `SAR_ENTER_COMMAND_CENTER` are also set by the tick when a living player is on that level, a teleport cannot skip them), the zones as boxes of the SoC zones (same coordinates in the mod levels: `PRI_ACTOR_IN_HOTEL`, `PRI_ACTOR_IN_HIDING_PLACE`, `SAR_MONOLITH_FIND`, `SAR_SOC_BUNKER`, `SAR_SECRET_DOOR_FIND`), the decoder (`PRI_MONOLITH_DECODER_GOT`, same check as `xr_conditions.any_actor_has_item`). The bunker and door steps need a player WITH the decoder (SoC `actor_has_decoder`).
2. Every task whose stage is open is given to EVERY living player once (`GiveTaskToClient`); finished stages close with the same flags the task sections complete on, so nothing finished comes back after a reload.
3. The stash: `alife():create("dev_decoder", pos, 215353, 2210)` (AI node and graph vertex of the hotel room, recomputed by `check_aes_chain.py --verify-stash`), a `treasure` map spot with the hint "Find the room with the secret stash" synced to every player (late joiners when they get the step), removed when somebody holds it. The spawn flag `SOC_AES_DECODER_SPAWNED` is set only when the engine accepted the object (a failed spawn is retried next tick; without the flag the Sarcophagus restrictor still spawns its copy).
4. Client tick: the SoC diary text of the stash ("Pripyat stash") shown once per player (`SOC_AES_NEWS_<NAME>`).
All waits are shared flags or positions; no step needs a living NPC (the leader of the stalkers is invulnerable; the C-Consciousness talk is a flag).

## Texts
Every new task id has title and description made of SoC strings (EN: Steam SoC `string_table_tasks_*`, `stable_storyline_info_*`; RU: the SoC strings of the CoP-port add-on), objective first, then the briefing after two `\n` on the first step. Nothing was invented: "Secret stash at Pripyat" / "Тайник на Припяти.", "Wish granter" ("Исполнитель желаний"), "Secret lab", the Doctor's two briefings, the diary text.
No money rewards: SoC pays nothing for these tasks (the stash holds the decoder), and the mod had none.

`LOCKED_START_OPEN_INFO` (door logic, read here), `AES_1_START_GO_TO_SARCOFAG_QUEST_TASK_INFO` / `PRI_START_GO_TO_CNPP_QUEST_TASK_INFO` (level restrictors, also set by the tick), `PRI_MONOLITH_DECODER_GOT` (new, read by the Sarcophagus restrictor), `SAR_START_OPEN_THE_DOOR_TO_MONOLITH_MANAGEMENT_QUEST_TASK_INFO` is no longer set (nothing reads it: it was only a link of the removed decoder task).

## Game test (one listen-host run per destination, host + one client, nothing human)
```
python build.py <out>\zzz.db --skip=soc_levels,weapon_upgrades,npc_attachments,arrival_facing
powershell -NoProfile -ExecutionPolicy Bypass -File <games>\tools\stalker_xrmpe\run_coop.ps1 -Map coop_l01_escape -Mode listen -Clients 1 -Owner aespri `
  -DbFile <out>\zzz.db -Hooks <repo>\patches\soc_aes_quests\tests\soc_aes_hooks.lua -Cfg no_respawn=1 -SoakSeconds 420 -CompareTimeout 10 -ResultDir <dir>
python <games>\tools\stalker_xrmpe\qa_verdict.py <dir> --prefix AES
```
`soc_aes_hooks.lua` starts on Cordon, fast-forwards the flags that restrictors and dialogs would give and travels by the guide vote. The destination is the `DEST` line (`pri`, `sar`, `con`, `x10`; make a copy of the file per run and use `-Owner aessar` etc.). The host and the joined client each assert that their own player got every step with the SoC title and description. `pri`: decoder object in the hotel room (section, position), stash steps, meeting steps, decoder in a player's inventory sets the info and starts "Secret lab". `sar`: Wish Granter steps, the restrictor copy of the decoder (no stash decoder), bunker / door zones by teleporting the players, door flag. `con`: infiltrate, one secret task, the talk, no hidden step. `x10`: the two X-10 steps. Not driven: the real pickup of the stash decoder by walking, the real door use (`sarcophagus_count\test\hooks_sarc.lua` drives that), the generators themselves.
